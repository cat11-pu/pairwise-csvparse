# csvparse

一个只依赖 Python 标准库的 CSV 解析内核。它不读写文件、不联网、不碰时钟，
只在内存里把一整篇文本读成记录，再把记录写回文本。

- 读取：整篇文本一次读入，每条记录都记住自己从第几行开始
- 引号：字段以引号开头才算被引号包裹；引号内两个连续引号表示一个引号，
  引号内的分隔符与换行都是字段数据
- 行尾：换行、单独的回车、CRLF 三种写法等价
- 头部 BOM 不进入第一个字段
- 列数：严格模式下列数不齐报错并给出记录起始行；宽松模式下短的补空字段，
  长的原样保留
- 写出：只在必要时加引号，写完再读回来得到同样的记录

## 目录

- csvparse/core.py：扫描器、记录对象与写出器
- tests/test_core.py：行为测试

## 跑测试

在项目根目录执行：

    python3 -m unittest discover -s tests -v
